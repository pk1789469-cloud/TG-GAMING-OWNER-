# TG Gaming Empire — Demo Android Project

This is a **demo-only starter project** for an Android app named TG Gaming Empire.
It includes a 30-second round timer, demo points, and a simple round-history display.

Important:
- This starter uses demo points only.
- It does not process real-money bets, deposits, withdrawals, or UPI payments.
- The project has not been built or tested in this environment. Build it with Android Studio or a compatible Gradle/Android SDK setup.
